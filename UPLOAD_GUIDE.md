# Upload guide

Open the appropriate folder in GitHub, select **Add file → Upload files**, select your files and commit the changes. For multiple folders, clone the repository with GitHub Desktop and copy files into the existing folders, then commit and push.

| Folder | Upload |
|---|---|
| 01_Thesis | Approved thesis PDF or Theseus link, presentation PDF/PPTX, references |
| 02_Theoretical_Design | Block diagram, calculations, design requirements |
| 03_LTspice_Simulation | .asc schematic, custom symbols and permitted model files |
| 04_Simulation_Results | PNG plots, exported CSV data and test conditions |
| 05_KiCad_PCB | .kicad_pro, .kicad_sch, .kicad_pcb, custom libraries, screenshots |
| 06_Manufacturing | Gerber ZIP, BOM CSV, CPL CSV and fabrication notes |
| 07_Hardware_Testing | Photos, test setup and measured data |
| 08_Engineering_Log | Debugging records and design revisions |

Keep the original project files editable. Use relative paths for dependencies. Do not upload personal information, credentials, proprietary third-party models or an unpublished thesis without permission. This repository is public; check visibility before uploading sensitive materials.
