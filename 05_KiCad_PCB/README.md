# KiCad PCB design

Upload the editable .kicad_pro, .kicad_sch and .kicad_pcb files, any custom symbol/footprint libraries and exported schematic, routing and 3D views.

## Design review checklist

- Confirm stackup and reference planes
- Confirm power routing and decoupling
- Review analog/RF return paths
- Verify footprints and pin mapping
- Run ERC and DRC
- Record fabrication constraints and impedance assumptions

Design rule compliance and fabrication readiness must be verified against the final project revision.
