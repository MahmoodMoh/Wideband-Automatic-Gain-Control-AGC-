## Core principles

- Closed-loop output amplitude regulation
- AD8336 gain control
- AD8310 logarithmic detection
- Error amplifier and feedback compensation
- Biasing, headroom, bandwidth and distortion

For equal impedances, voltage gain in dB is 20 log10(Vout/Vin). Output-level regulation is not the same as maintaining a fixed gain when input amplitude changes.
