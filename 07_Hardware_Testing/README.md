# Hardware testing

Physical measurements are pending documentation. Upload prototype photos, instrument settings, test diagrams and measured results here.

## Proposed test sequence

1. Inspect assembly and check for supply shorts.
2. Verify supply rails and DC bias with current-limited supplies.
3. Verify signal path and VGA response.
4. Evaluate closed-loop output regulation with changing input amplitude.
5. Evaluate frequency response, settling and distortion.
6. Compare measured results against simulation under matching conditions.

Use [measurements.csv](measurements.csv) to record results. Do not label simulations as hardware measurements.
